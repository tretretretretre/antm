# AINTM Tool Menu

Use tools only when they serve the canonical operating chain. Model assignment
lives in `config/model-routing.yml`.

## Available core tools

| Tool | Best AINTM use |
|---|---|
| GPT-5.6 Sol / Codex | Strategy, orchestration, code, and final review |
| Grok 4.6 / X Search | X-native discovery, social evidence, and drafting |
| Gemini Flash/Lite | Vision, extraction, compression, titles, bulk synthesis |
| Tavily | Broad discovery and primary-source location/extraction |
| `yt-dlp` / YouTube APIs | Channel, upload, metadata, caption, and transcript collection |
| FFmpeg / FFprobe | Deterministic local media assembly and quality checks |
| Hermes profiles and cron | Role isolation, scheduling, and owner-ready artifacts |
| n8n | Optional approval/orchestration layer when it reduces complexity |
| Postiz | Optional publishing layer after approval and integration verification |

## Generation tools

| Need | Default | Escalation |
|---|---|---|
| Everyday images/carousels | Nano Banana 2 | Nano Banana Pro or GPT-Image-2 |
| Fast reference imagery | Grok Imagine Image 2.0 | Premium image route |
| Iterative video | Gemini Omni Flash | Veo 3.1 |
| Efficient video | Veo 3.1 Lite | Veo 3.1 hero shots |
| Short reference video | Grok Imagine Video 1.5 | Omni/Veo assembly |
| Draft voice | edge TTS | xAI final voice; Gemini TTS experiment |

## Adoption rule

Do not add a vendor because it is fashionable. Record the measured gap,
compare quality/cost/latency against the existing route, obtain approval for
spend or new credentials, and keep a reversible fallback.
