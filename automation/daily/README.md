# AINTM Daily Automation Workspace

Cron-driven Bots write only experimental research, format plans, drafts, and reviews here. Nothing in this directory is approved for publication until the owner explicitly approves it.

Canonical rolling files:
- `latest-research.md`
- `latest-format-lab.md`
- `latest-prototypes.md`
- `latest-review.md`

Dated files preserve each day's experiments and should not contain credentials or copied creator transcripts.
