# AINTM Daily Automation Workspace

Scheduled agents write only experimental research, strategy, drafts, and
reviews here. Nothing in this directory is approved for production or
publication until the owner explicitly approves it.

Canonical rolling files:
- `latest-research.md`
- `latest-strategy.md`
- `latest-content.md`
- `latest-review.md`

Dated files preserve each day's experiments and should not contain credentials or copied creator transcripts.
